二、我們不會主動蒐集的資訊

本 App 全程不會透過任何程式碼、SDK 或埋點方式主動擷取、傳輸以下資料，無將使用者資訊對外散佈、販售、出租之行為：

  • 身分類資訊：姓名、行動電話號碼、電子郵件、身分證件、社群帳號、住址等個人識別標示；
  • 付款資訊：銀行卡號、支付密碼、Apple ID 帳號密碼、消費明細；
  • 裝置追蹤標示：IDFA、裝置序號、IMEI 等硬體唯一辨識碼；
  • 位置資訊：GPS 定位、移動軌跡；
  • 使用者內容：相簿、聯絡人、簡訊、聊天記錄、本機檔案；
  • 第三方 App 內部資料：受管理應用的內容資料；
  • 網路行為：瀏覽記錄、搜尋紀錄；
  • 診斷與埋點資料：當機日誌、使用行為統計、點擊熱區圖等。

本 App 未整合任何第三方統計、廣告、推播、埋點 SDK，不存在第三方主動或被動取得本機資料的管道。

三、僅儲存於本機的必要資料

為實現核心管理功能，本 App 僅將設定資料儲存於您裝置的本機沙盒與 App Group 共用容器，無雲端同步、無遠端備份，僅該裝置可檢視。解除安裝 App 時所有資料將自動永久刪除。

1. 應用管理群組設定

  • 儲存內容：您建立的隱藏 / 鎖定群組名稱、勾選的應用匿名權杖（Token）、定時起迄時間、每週重複規則、每日使用時長上限、群組開關狀態。
  • 用途：實現應用定時 / 時長限制隱藏、鎖定之核心管理功能。

2. 桌面圖示偽裝設定

  • 儲存內容：您手動選取的 Alternate Icon 識別碼。
  • 用途：變更本 App 顯示於桌面的圖示樣式。

3. 螢幕使用本機統計資料

  • 儲存內容：iOS 系統 DeviceActivity API 回傳的各應用本機使用時長。
  • 用途：首頁顯示裝置應用使用統計，僅於本機渲染，不會對外傳輸。

4. 訂閱匿名憑證

  • 儲存內容：Apple 交易系統回傳的原始交易識別碼（original_transaction_id）、訂閱到期時間、訂閱週期標示。
  • 用途：僅供本機驗證當前裝置 VIP 權益有效性、防止竄改本機訂閱狀態，絕不使用於使用者追蹤、使用者肖像建立或與第三方共享。
📌 特別說明：本 App 不會儲存您的 Apple ID 帳號、姓名、付款卡號、收件地址等可辨識個人身份之資訊。所有扣款作業均由 Apple 官方 App Store 獨立處理。

付款流程完全由 Apple 管控

所有 VIP 訂閱扣款、自動續約皆於 App Store 系統內完成，本 App 無法介入付款流程，不會蒐集、儲存卡號、支付密碼、Apple ID 等付款隱私資訊。

VIP 訂閱權益透過 Apple 交易識別碼綁定當前裝置。重新安裝或更換裝置後，需透過 Apple ID 還原購買內容；本 App 不儲存個人帳號資訊，亦無法跨裝置同步訂閱狀態。

訂閱自動續約由 Apple 帳號獨立管控，您可隨時前往「iPhone 設定 > Apple ID > 訂閱項目」關閉自動續約，關閉後到期將不再自動扣款。

解除安裝 App 後，本機儲存的所有訂閱憑證將永久刪除，無法復原。
