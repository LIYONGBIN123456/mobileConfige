당사는 《중국 사이버보안법》《데이터보안법》《개인정보보호법》《미성년자 인터넷보호조례》와 App Store 개인정보 규정, GDPR, CCPA 등 전 세계 표준 개인정보 규정을 엄격히 준수합니다.

🔒 본 앱 자체 클라우드 서버가 없습니다. 사용자 로컬 데이터를 업로드하지 않고 개인식별정보를 수집하지 않으며 광고/통계/추적용 서드파티 SDK를 탑재하지 않습니다. 모든 기능 로직은 기기 내에서만 작동합니다.

본 앱을 다운로드, 설치, 실행, 사용하는 경우 본 방침 전체 내용을 충분히 읽고 이해한 뒤 자발적으로 동의한 것으로 간주합니다. 본 방침 내용에 동의하지 않으시면 즉시 앱을 삭제하고 모든 이용을 중단해 주십시오.

관리 기능 구현을 위해 본 앱은 사용자 기기 로컬 샌드박스 및 App Group 공유 영역에 설정 데이터만 저장합니다. 클라우드 동기화나 원격 백업은 없고 해당 기기에서만 열람 가능. 앱 삭제 시 모든 데이터가 자동으로 영구 삭제됩니다.

  • 저장 내용: 생성한 숨김/잠금 그룹 이름, 선택한 앱 익명 토큰, 시작/종료 시간, 주간 반복 규칙, 일일 사용 한도, 그룹 활성화 상태.
  • 사용 목적: 시간/사용량 기준 앱 숨김 및 잠금 핵심 기능 구현.

2. 아이콘 위장 설정

  • 저장 내용: 사용자가 직접 선택한 Alternate Icon 식별값.
  • 사용 목적: 홈화면 앱 아이콘 이미지 변경.

3. 스크린타임 로컬 통계 데이터

  • 저장 내용: iOS DeviceActivity API가 반환하는 각 앱의 일일 사용시간.

4. 앱 내 구매 및 VIP 이용 안내

결제 전 과정 Apple 관리

VIP 구매 요금 및 자동 갱신은 모두 App Store 내에서 처리됩니다. 본 앱은 결제 프로세스에 개입할 수 없으며 카드번호, 결제 비밀번호, Apple ID 등 결제 관련 개인정보를 수집하거나 저장하지 않습니다.

구매 권한 기기 귀속

VIP 혜택은 Apple 거래 ID로 현재 기기에 연결됩니다. 앱 재설치나 기기 변경 후 Apple ID로 구매 복구를 진행해야 합니다. 본 앱은 개인 계정 정보를 저장하지 않으며 기기 간 구매 상태 동기화가 불가합니다.

자동 갱신 관리

구매 자동 갱신은 Apple 계정에서 독자 관리하며 'iPhone 설정 > Apple ID > 구독'에서 언제든지 끌 수 있습니다. 자동 갱신을 끊으면 기간 만료 후 추가 요금이 청구되지 않습니다.

구매 데이터 삭제

앱을 삭제하면 로컬에 저장된 모든 구매 인증 정보가 영구 삭제되며 복구할 수 없습니다.
