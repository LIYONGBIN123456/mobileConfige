I. Введение

Настоящая Политика конфиденциальности распространяется на приложение Cloak (далее «Приложение») — локальный инструмент управления, созданный на основе официальных фреймворков Apple FamilyControls, DeviceActivity и ManagedSettings. Сервисы включают скрытие приложений, запланированную блокировку, суточные лимиты времени использования, маскировку иконки рабочего стола, управление группами и полный набор функций после оформления VIP-подписки.

Мы строго соблюдаем Закон о кибербезопасности КНР, Закон о безопасности данных, Закон о защите персональных данных, Правила защиты несовершеннолетних в сети, а также стандарты конфиденциальности App Store, GDPR, CCPA и другие общепринятые глобальные нормы.

🔒 У приложения нет собственных облачных серверов. Никакие локальные данные пользователя не передаются в сеть, мы не собираем персональные идентификационные сведения, не интегрируем сторонние SDK для рекламы, аналитики или отслеживания. Вся бизнес-логика работает исключительно локально на вашем устройстве.

Загружая, устанавливая, открывая и используя Приложение, вы подтверждаете, что полностью ознакомились, поняли и добровольно приняли все положения настоящей Политики. Если вы не согласны с любым пунктом документа, немедленно удалите Приложение и прекратите любое его использование.

II. Данные, которые мы не собираем целенаправленно

На протяжении всего времени работы Приложение не получает и не передаёт любые из перечисленных ниже данных через код, SDK или инструменты отслеживания. Мы не распространяем, не продаём и не сдаём в аренду пользовательскую информацию третьим лицам:

  • Идентификационные данные: ФИО, номер телефона, электронная почта, удостоверения личности, аккаунты социальных сетей, адрес проживания и другие персональные маркеры;
  • Платёжные данные: Номера банковских карт, пароли для оплаты, учётные данные Apple ID, история транзакций;
  • Идентификаторы отслеживания устройства: IDFA, серийный номер гаджета, IMEI и другие уникальные аппаратные коды;
  • Геоданные: Координаты GPS, маршруты передвижения;
  • Пользовательский контент: Галерея, контакты, SMS, переписки, локальные файлы;
  • Внутренние данные сторонних приложений: Содержимое управляемых программ;
  • Сетевые действия: История просмотров, поисковые запросы;
  • Диагностика и трекинг: Журналы сбоев, статистика взаимодействия, тепловые карты кликов.

В Приложение не интегрированы сторонние SDK для аналитики, рекламы и пуш-уведомлений, поэтому отсутствуют каналы пассивного или активного получения локальных данных внешними сервисами.

III. Обязательные данные, хранящиеся только локально

Для работы основных функций управления Приложение сохраняет только конфигурационные сведения в локальной песочнице и общем контейнере App Group вашего устройства. Облачная синхронизация и удалённые резервные копии отсутствуют, данные доступны исключительно на данном гаджете. При удалении программы все сведения стираются навсегда автоматически.

1. Конфигурация групп управления приложениями

  • Хранимые сведения: Названия групп скрытия/блокировки, анонимные токены выбранных приложений, время начала и завершения расписания, еженедельные правила повторения, суточные лимиты времени, статус активности группы.
  • Цель: Реализация основных функций запланированного и лимитированного скрытия/блокировки программ.

2. Настройки маскировки иконки

  • Хранимые сведения: Идентификаторы Alternate Icon, выбранные пользователем вручную.
  • Цель: Изменение отображаемой иконки Приложения на рабочем столе.

3. Локальная статистика времени экрана

  • Хранимые сведения: Суточная длительность использования каждой программы, возвращаемая API DeviceActivity iOS.
  • Цель: Отображение статистики устройства на главном экране; данные не передаются за пределы гаджета.

4. Анонимные сертификаты подписки

  • Хранимые сведения: Оригинальный идентификатор транзакции original_transaction_id, дата окончания подписки, маркеры цикла подписки от системы платежей Apple.
  • Цель: Только локальная проверка действительности VIP-доступа и предотвращение подделки статуса подписки. Данные никогда не используются для отслеживания пользователей, создания профилей или передачи третьим лицам.
📌 Особое примечание: Приложение не хранит данные Apple ID, ФИО, номера карт или адреса доставки, по которым можно определить личность. Все списания осуществляются эксклюзивно через официальный App Store Apple.

IV. О покупках внутри приложения и VIP-подписках

Полный контроль платежей со стороны Apple

Все списания и автоматическое продление VIP-подписок обрабатываются внутри системы App Store. Приложение не имеет доступа к платёжному процессу, не собирает и не сохраняет номера карт, пароли для оплаты или данные Apple ID.

Подписка привязана к устройству

VIP-преимущества привязываются к гаджету через идентификаторы транзакций Apple. При переустановке или смене устройства нужно восстановить покупки через Apple ID. Приложение не хранит личные аккаунты и не синхронизирует статус подписки между разными устройствами.

Управление автопродлением

Автоматическое продление регулируется только аккаунтом Apple. Вы можете отключить его в любое время через «Настройки iPhone > Apple ID > Подписки». После отключения платежи не будут списаны по окончании текущего периода.

Удаление данных подписки

При удалении Приложения все локальные сертификаты подписки стираются навсегда, восстановить их невозможно.

V. Требуемые системные разрешения

Все разрешения необходимы для работы ключевых функций управления. Отключение любого из них приведёт к прекращению работы соответствующих инструментов.

1. Разрешение «Время экрана» (FamilyControls)

Цель: Получение анонимных маркеров приложений для скрытия, запланированной блокировки и ограничения времени использования. Программа получает только неидентифицирующие теги, не имеет доступа к внутреннему контенту других приложений.

2. Разрешение уведомлений

Цель: Оповещения о срабатывании правил управления и превышении суточного лимита. Можно отключить в системных настройках в любое время.

3. Разрешение смены иконки (Alternate Icon API)

Цель: Изменение иконки Приложения через официальные API iOS после ручного выбора. Меняется только значок этой программы, другие приложения не затрагиваются. Стандартную иконку можно вернуть в настройках.

  • Право на удаление: Очистить группы прямо в приложении; при удалении программы все локальные данные стираются полностью;

VIII. Защита данных несовершеннолетних

Приложение предназначено для всех возрастных групп, мы не собираем целенаправленно никакие персональные сведения о детях. Если опекун использует программу для управления устройством ребёнка, все настройки сохраняются только локально на гаджете опекуна, данные о действиях детей не загружаются в облако. Несовершеннолетним рекомендуется прочитать всю Политику вместе с опекуном перед использованием.
