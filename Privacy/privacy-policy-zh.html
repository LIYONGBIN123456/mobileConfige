一、前言

本隐私政策适用于 Cloak 应用（下称「本 App」），一款基于 Apple 官方 FamilyControls、DeviceActivity、ManagedSettings 框架开发的本地应用管控工具，提供应用隐藏、定时锁定、每日使用时长限额、桌面图标伪装、分组管理、VIP 订阅解锁全功能等服务。

我们严格遵循《中华人民共和国网络安全法》《数据安全法》《个人信息保护法》《未成年人网络保护条例》以及 App Store 平台隐私规范、GDPR、CCPA 等全球通用隐私法规。

🔒 本 App 无自有云端服务器，不上传任何用户本地数据，不采集个人身份信息，未集成任何第三方广告 / 统计 / 埋点 SDK，全部业务逻辑仅在您设备本地运行。

您下载、安装、打开、使用本 App，即视为已完整阅读、充分理解并自愿同意本隐私政策全部条款；若您不认可本政策任意内容，请立即卸载本 App，停止一切使用行为。

二、我们不会主动收集的信息

本 App 全程不会通过任何代码、SDK 或埋点方式主动获取、传输以下数据，不存在对外分发、出售、出租用户信息行为：

  • 身份类信息：姓名、手机号、邮箱、身份证件、社交账号、住址等个人身份标识；
  • 支付信息：银行卡号、支付密码、Apple ID 账号密码、支付账单明细；
  • 设备追踪标识：IDFA、设备序列号、IMEI 等唯一硬件识别码；
  • 位置信息：GPS 定位、出行轨迹；
  • 用户内容：相册、通讯录、短信、聊天记录、本地文件；
  • 第三方 App 内部数据：被管控应用的内容数据；
  • 网络行为：浏览记录、搜索记录；
  • 诊断与埋点数据：崩溃日志、使用行为统计、点击热力图等。

本 App 未集成任何第三方统计、广告、推送、埋点 SDK，不存在第三方主动或被动获取本地数据的通道。

三、仅在本地存储的必要数据

为实现管控核心功能，本 App 仅在您设备本地沙盒及 App Group 共享容器内存储配置数据，无云端同步、无远程备份，仅本机可见。卸载 App 时全部数据自动永久清除。

1. 应用管控分组配置

  • 存储内容：您创建的隐藏 / 锁定分组名称、勾选的应用匿名标识（Token）、定时起止时间、每周重复规则、每日使用时长限额、分组开关状态。
  • 用途：实现应用定时 / 时长隐藏、锁定管控核心功能。

2. 桌面伪装配置

  • 存储内容：您主动选择的 Alternate Icon 标识。
  • 用途：更换本 App 桌面图标显示样式。

3. 屏幕使用本地统计数据

  • 存储内容：iOS 系统 DeviceActivity API 返回的本地各应用使用时长。
  • 用途：首页展示本机应用使用统计，仅本地渲染，不向外传输。

4. 订阅权益匿名凭证

  • 存储内容：Apple 交易系统回传的原始交易标识符（original_transaction_id）、订阅到期时间、订阅周期标识。
  • 用途：仅用于本地校验当前设备 VIP 权益有效性、防止本地篡改订阅状态，绝不用于用户追踪、用户画像或第三方共享。
📌 特别说明：本 App 不存储您的 Apple ID 账号、姓名、支付卡号、收货地址等可定位个人身份的信息。所有支付扣费由 Apple 官方 App Store 独立处理。

四、App 内购与 VIP 订阅说明

支付流程完全由 Apple 管控

所有 VIP 订阅扣费、自动续费均在 App Store 系统内完成，本 App 无法介入支付环节，不会收集、存储银行卡号、支付密码、Apple ID 账号等支付隐私信息。

订阅权益绑定设备

VIP 订阅权益通过 Apple 交易标识绑定当前设备。重装 App 或更换设备后，您需通过 Apple ID 恢复购买，本 App 本身不存储个人账号信息，亦无法跨设备同步订阅状态。

自动续费管理

订阅自动续费由 Apple 账户独立控制，您可随时前往「iPhone 设置 > Apple ID > 订阅项目」关闭自动续费，关闭后订阅到期不再自动扣费。

订阅数据清除

卸载 App 后本地存储的订阅凭证全部永久清除，无法恢复。

五、所需系统权限说明

所有权限均为实现核心管控功能所必需，关闭对应权限后相关功能直接失效。

1. 屏幕使用时间权限（FamilyControls）

用途：读取应用匿名标识、实现应用隐藏 / 定时锁定 / 时长限额管控。仅获取应用无身份标识，无法读取任何 App 内部内容。

2. 通知权限

用途：管控规则生效提醒、使用时长超限提醒。可随时在系统设置中关闭。

3. 桌面图标更换权限（Alternate Icon API）

用途：通过 iOS 官方 API，在用户主动选择后更换本 App 桌面图标。仅修改本 App 自身显示样式，不修改其他任何应用。用户可随时在系统设置中恢复默认图标。
